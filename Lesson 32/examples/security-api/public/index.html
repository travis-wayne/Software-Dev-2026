CORS (Cross-Origin)

Browsers block JS from fetching data from other domains (Same-Origin Policy). CORS is the backend telling the browser "It's okay, let them in."

XSS (Cross-Site Scripting)

Attackers inject malicious <script> tags into your database. If you render it as HTML, the browser executes it and they steal your data.

CSRF (Cross-Site Forgery)

Attackers trick the browser into sending requests to your bank. If the browser auto-attaches cookies, the bank thinks you made the request.
