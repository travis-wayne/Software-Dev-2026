1. What does CSR stand for?
Client-Side Rendering
2. Which Next.js file contains global layout and CSS imports for all pages?
pages/_app.js
3. What is the main SEO advantage of SSR/SSG over CSR?
Search engines can read the complete HTML content immediately upon request, rather than seeing an empty div.
4. Which function runs on every request and has access to cookies and sessions?
getServerSideProps
5. What does fallback: false mean in getStaticPaths?
Any path not in the paths array will return a 404 Not Found page.
6. Why should you use <Link> instead of <a> for internal navigation?
The Link component prefetches pages in the background, making internal navigation feel instant without a full page reload.
7. What does revalidate: 60 do in getStaticProps?
It regenerates the static page in the background at most once every 60 seconds (Incremental Static Regeneration or ISR).
