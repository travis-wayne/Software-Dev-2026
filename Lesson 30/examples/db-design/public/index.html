Session 30 · Normalization & JOINs

Database Design

Learn how to structure tables efficiently using Normalization, and how to link them together using Foreign Keys and the three core Relationship types.

1:1

One-to-One

One record in Table A belongs to exactly one record in Table B.

Example: User ↔ User Profile
Implementation: Foreign Key with a UNIQUE constraint.

1:N

One-to-Many

One record in Table A can have many records in Table B.

Example: User ↔ Posts
Implementation: A standard Foreign Key in the child table.

M:N

Many-to-Many

Many records in Table A can relate to many in Table B.

Example: Posts ↔ Tags
Implementation: Requires a 3rd Junction Table (e.g., post_tags) holding Foreign Keys to both.
