# Lesson 18: Computer Science Basics — Algorithms (Sorting & Searching)

## 🎯 Learning Objectives

By the end of this session, students will be able to:
1. Explain what an algorithm is and why efficiency matters when choosing one.
2. Implement **Linear Search** and state its O(n) complexity.
3. Implement **Binary Search** and explain why it requires a sorted array.
4. Implement **Bubble Sort** by tracing the inner and outer loop logic.
5. Implement **Selection Sort** and explain how it differs from Bubble Sort.
6. Compare all four algorithms using Big O notation.
