MongoDB & Mongoose

Learn how to break free from strict tables. Store your data as flexible JSON documents, and use Mongoose to bring structure back when you need it.

Documents (Not Rows)

Instead of rows in a table, MongoDB stores data in BSON (Binary JSON) documents. It looks and feels exactly like a JavaScript Object.

Collections (Not Tables)

Instead of rigid tables, documents are grouped into Collections. One document in a collection can have completely different fields than another!

The _id Field

MongoDB automatically generates a unique identifier called _id for every document. No need to worry about auto-incrementing integers.

Mongoose (ODM)

While MongoDB is schema-less, total freedom causes bugs. Mongoose adds schemas and validation directly into your Node.js code.

Mongoose Cheat Sheet

How SQL queries translate to Mongoose Object methods in JavaScript.

SQL Equivalent Mongoose Syntax What it does
INSERT INTO Product.create({...}) Validates object against Schema and saves to DB.
SELECT * FROM Product.find() Returns an array of all matching documents.
SELECT * WHERE id=1 Product.findById(id) Returns a single document by its unique _id.
UPDATE x WHERE id=1 Product.findByIdAndUpdate(id, data) Finds document by ID and applies updates.
DELETE FROM WHERE id=1 Product.findByIdAndDelete(id) Removes the document entirely.
