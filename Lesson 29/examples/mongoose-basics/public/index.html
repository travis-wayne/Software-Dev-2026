MongoDB & Mongoose

Move beyond rigid tables. Store data as flexible JSON documents, validated and shaped by Mongoose schemas.

🆚

NoSQL vs SQL

SQL stores data in fixed tables with rigid schemas. MongoDB stores flexible JSON documents — fields can vary per record, and nesting is natural.

NoSQL = "Not Only SQL"

📄

Documents & Collections

A Document is a single JSON-like record (equivalent to a row). A Collection is a group of documents (equivalent to a table).

Collection = products, Document = {…}

🧱

Schema & Models

Mongoose adds a validation layer on top of MongoDB. A Schema defines the shape; a Model is the interface you query.

mongoose.model('Product', schema)

⚡ SQL vs MongoDB — Terminology

SQL Concept MongoDB Equivalent Description
Database Database Top-level container for all data
Table Collection Groups related documents/rows
Row Document A single record of data
Column Field A single key-value pair in a document
Primary Key _id (ObjectId) Unique identifier — auto-generated
JOIN $lookup / embed Link data — or just embed it in the document
INDEX Index Speed up queries on specific fields
Schema Mongoose Schema Optional but recommended — enforced by Mongoose

📝 Mongoose Schema & Model

The Sheriff: defines rules before any data reaches MongoDB.

import mongoose from 'mongoose';

// 1. Define the shape (Schema)
const productSchema = new mongoose.Schema({
  name: {
    type:     String,
    required: [true, 'Product name is required'],
    trim:     true,
  },
  price: {
    type:     Number,
    required: true,
    min:      [0, 'Price cannot be negative'],
  },
  description: {
    type:    String,
    default: '',
  },
  inStock: {
    type:    Boolean,
    default: true,
  },
}, { timestamps: true });  // adds createdAt & updatedAt automatically

// 2. Compile into a Model (the query interface)
const Product = mongoose.model('Product', productSchema);

// 3. Use it — Mongoose validates before hitting MongoDB
const laptop = await Product.create({ name: 'Laptop', price: 999.99 });
const all     = await Product.find();
await Product.findByIdAndUpdate(id, { price: 849 }, { new: true, runValidators: true });
await Product.findByIdAndDelete(id);
