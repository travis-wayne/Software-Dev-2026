Middleware Functions

Code that runs in the middle of every request. It receives req, res, and — critically — next(). Without calling next(), the request freezes forever.

Real-world uses

Logging every request to the console
Checking API keys / JWT tokens
Parsing JSON request bodies
Rate-limiting abusive clients

Environment Variables

Secrets like passwords and API keys must never be typed directly in code. They live in a local .env file that Git never sees.

4-step setup

  1. 1 Create .env file
  2. 2 Add .env to .gitignore
  3. 3 pnpm install dotenv
  4. 4 Call dotenv.config() at top of server

Global Error Handler

When a route throws an error (e.g. reading undefined.name), Express normally crashes. A 4-argument handler catches it and sends a clean JSON response.

The magic signature

app.use((err, req, res, next) => {
  res.status(500).json({
    error: err.message
  });
});

⚠ Must have exactly 4 args — no more, no less
