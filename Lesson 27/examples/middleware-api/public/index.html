Middleware, Errors & Environments

Level up your Express app. Intercept requests, securely store secrets, and gracefully handle server crashes with global error handlers.

Middleware Functions

Functions that execute during the request lifecycle. They can modify req, send a response early, or pass control to the next function using next().

Common Uses

  • Logging (e.g., "GET /api/users")
  • Authentication (checking API keys/tokens)
  • Parsing JSON bodies (express.json())

Environment Variables

Keep secrets safe! Passwords, API keys, and connection strings should never be in your code. Store them in a .env file instead. 

// 1. npm install dotenv
// 2. Add to server.js:
import dotenv from 'dotenv';
dotenv.config();

// 3. Access your key:
console.log(process.env.API_SECRET_KEY);

Global Error Handler

If a route crashes (e.g. reading a property of undefined), the Express server will crash or hang. A global error handler catches it.

It is defined by having exactly 4 arguments:
app.use((err, req, res, next) => {
  res.status(500).json({ error: 'Oops!' });
});
