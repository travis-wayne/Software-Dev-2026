What is an API?

API = Application Programming Interface. It is the contract between two pieces of software that defines how they communicate.

The Restaurant Analogy

Client →React frontend (the customer)
API →Express server (the waiter)
DB →Database (the kitchen)

Express.js

A minimal Node.js framework that gives you a clean syntax for defining routes and handling HTTP requests. 

// The full anatomy of a route:
app.get('/api/books', (req, res) => {
  res.json({ data: books });
});

Request & Response

Every route callback receives two objects:

req — What the client sent
req.params — URL segments (/books/:id)
req.body — JSON sent in POST/PUT
req.query — URL query strings
res — What we send back
res.json() — Send a JSON object
res.status(404) — Set HTTP status code

The 4 HTTP Methods → CRUD

Every REST API operation maps to one of four HTTP verbs.

Method CRUD Operation Express Code Example URL Status
GET Read app.get() /api/books 200 OK
POST Create app.post() /api/books 201 Created
PUT Update app.put() /api/books/:id 200 OK
DELETE Delete app.delete() /api/books/:id 200 OK

🔑 The Most Important Line: Middleware

Middleware is code that runs between the incoming request and your route handler. The most critical one for APIs:

app.use(express.json());

Without this, req.body is undefined in POST and PUT requests. Always add it before your routes.
