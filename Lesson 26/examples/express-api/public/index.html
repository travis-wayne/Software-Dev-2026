🎓 How APIs Work

You are looking at a frontend client. The code for the API runs on your Node.js server. When you click a button below, JavaScript (using fetch()) sends an HTTP Request to your Express server. The server processes the request, modifies its array of books, and sends back a JSON Response.

GET /api/books

Retrieves the complete list of books from the server.

POST /api/books

Creates a new book using the JSON body provided.

PUT /api/books/:id

Updates an existing book by its URL parameter ID.

DELETE /api/books/:id

Deletes a book based on the URL parameter ID.
