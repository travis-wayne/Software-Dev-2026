Debugging War Stories Lab

Don't rely on auto-fix buttons! You are the engineer now. Edit the buggy code and verify your fix.

🐛 Scenario A: The Missing Closing Tag Collapse

An unclosed tag is ruining the layout, making everything below it a giant heading!

Excellent! You closed the <h1> tag. Leaving tags open causes the browser to incorrectly guess where elements end.
<h1>Welcome to my site
<h1>Welcome to my site</h1>

🐛 Scenario B: The Accessibility Audit Failure

The image is failing screen readers. A visually impaired user will only hear the filename.

Perfect! You added an alt attribute. Accessibility is non-negotiable in modern web development!
<img src="hero.jpg">
<img src="hero.jpg" alt="Hero Image">

🐛 Scenario C: The "Div Soup" SEO Disaster

Google can't read the article structure because the developer only used generic <div> tags.

Great refactor! Using semantic tags like <main> or <article> helps Search Engine bots and screen readers navigate your content easily.
<div class="story">...</div>
<article>...</article>

🐛 Scenario D: The Language Barrier

The root tag is missing something important. Screen readers don't know what language this page is written in!

Nailed it! Adding lang="en" to the <html> tag ensures translation tools and screen readers process the text correctly.
<html>
<html lang="en">
