# Lesson 1: Intro to Software Engineering, Development Environment & HTML Basics

## 🎯 Learning Objectives
By the end of this foundational session, students will:
- Understand the software engineering lifecycle and career paths (Frontend, Backend, DevOps, Full-Stack)
- Configure an ergonomic, high-productivity development environment using Visual Studio Code and the terminal CLI
- Master essential command-line interface (CLI) navigation (`cd`, `ls`/`dir`, `mkdir`, `touch`/`new-item`)
- Architect valid, semantic HTML5 document structures (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Implement core HTML elements (headings, paragraphs, anchor links, images, semantic containers, and lists)

## 📚 Prerequisites
- No prior programming experience required!
- A computer with Windows, macOS, or Linux
- A curious mindset and willingness to experiment
