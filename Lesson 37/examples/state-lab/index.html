The State Analogy: A Whiteboard in an Office

📝

useState

A Post-it note on your own desk.

Only you can see it. If you throw it away, it's gone.

const [count, setCount] = useState(0);
📋

Context API

The office noticeboard.

Everyone can read it, but every time someone writes on it, EVERYONE looks up (re-renders).

const { user } = useContext(AuthContext);
// Re-renders even if only 'theme' changes!
📄

Redux / Zustand

A shared Google Doc.

Anyone can open just the section they need. When Section A changes, only Section A readers are notified.

const items = useSelector(s => s.cart.items);
// 100% immune to 'theme' changes

Redux Toolkit vs Zustand

Redux Toolkit

Strict, structured, generates action creators.

const cartSlice = createSlice({
  name: 'cart',
  initialState: { items: [] },
  reducers: {
    addItem: (state, action) => {
      // Immer allows safe mutations
      state.items.push(action.payload);
    }
  }
});

Zustand

Lightweight, hook-based, minimal boilerplate.

const useCartStore = create((set) => ({
  items: [],
  addItem: (product) => set(state => ({
    // Return a new immutable state object
    items: [...state.items, product]
  }))
}));

Using Redux DevTools

The Redux DevTools extension allows you to inspect every state change, action payload, and even "time-travel" back to previous states.

  1. Install the extension from the Chrome Web Store (it's free).
  2. Use configureStore() in your app — it connects automatically.
  3. Open your browser Developer Tools (F12) and click the Redux tab.
