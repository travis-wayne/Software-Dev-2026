IaaS

Infrastructure as a Service

You rent raw virtual machines (e.g., AWS EC2). You must install Linux, manage SSH keys, configure security group firewalls, and patch OS vulnerabilities yourself.

Control: HIGH Maintenance: HIGH
PaaS

Platform as a Service

You upload your code repository (e.g., Heroku, Vercel, Elastic Beanstalk), and the cloud provider manages server patching, OS runtimes, and load balancing.

Control: MEDIUM Maintenance: LOW
FaaS

Serverless FaaS / Storage

You write modular event handlers (AWS Lambda) and store static objects (AWS S3). AWS provisions containers on demand and scales from 0 to 10,000 instantly!

Idle Cost: $0.00 Maintenance: ZERO
