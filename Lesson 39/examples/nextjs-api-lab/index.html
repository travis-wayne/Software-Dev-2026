SQL Injection Guard (Parameterized Queries)

Compare parameterized safe queries vs vulnerable string concatenation.

🛡️ Safe (Parameterized)

query('SELECT * FROM projects WHERE tech = $1', [input])

Parameters are sent separately to the Postgres engine. Injection attempts are treated as literal strings, not executable code.

⚠️ Unsafe (String Concat)

query("SELECT * FROM projects WHERE tech = '" + input + "'")

Malicious input like ' OR 1=1;-- alters the SQL logic, bypassing auth or dropping tables.
