How secretKeyRef Works

The secretKeyRef pattern injects sensitive credentials into your pods without hardcoding them in YAML.

  1. Create a secret in the cluster (e.g. via CLI or External Secrets Operator).
  2. Reference the secret in your deployment using valueFrom: secretKeyRef.
  3. Kubernetes fetches the secret securely from etcd and mounts it as an environment variable (DATABASE_URL).
  4. The container's application reads process.env.DATABASE_URL seamlessly!
