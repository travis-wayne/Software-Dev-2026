1. Frontend UI Layer

Server Components handle secure data fetching directly from the DB, while Client Components handle interactivity. This reduces JS bundle size.

Code Sample: 
// app/page.tsx (Server Component)
export default async function Page() {
  // Direct DB call, never shipped to browser
  const users = await prisma.user.findMany();
  
  return (
    <main>
      <UserList initialUsers={users} />
    </main>
  );
}
💡 Pro Tip:

Never fetch data in a useEffect in the Next.js App Router if you can fetch it in a Server Component instead.
