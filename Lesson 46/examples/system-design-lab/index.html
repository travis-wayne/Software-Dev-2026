The RESHADED Framework

Master the 8-step process for acing any system design interview.

Step 1 of 8
R

Requirements Clarification (5-10 mins)

  • Define Functional Requirements (What does it do?)
  • Define Non-Functional Requirements (Scale, Latency, Availability)
  • Determine Read vs Write ratio
Pro Tip: Never start drawing before asking questions!
E

Estimation (5-10 mins)

  • Calculate QPS (Queries Per Second)
  • Estimate Storage for 5 years
  • Estimate Bandwidth (Network I/O)
D

Deep Dive (10-15 mins)

  • Pick a critical component (e.g., caching, DB scaling)
  • Explain failure scenarios and mitigation
