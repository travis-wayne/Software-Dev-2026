# Lesson 46: System Design Interview Prep

## 🎯 Learning Objectives
By the end of this session, students will:
- Apply the RESHADED framework to any system design problem
- Perform back-of-the-envelope capacity estimations confidently
- Design a URL Shortener (TinyURL) end-to-end under interview conditions
- Articulate trade-offs for every architectural decision they make
- Identify bottlenecks and propose scalability solutions

## 📚 Prerequisites
- Lesson 28 (Databases: SQL vs NoSQL)
- Lesson 34 (Deployment Basics)
- Lesson 45 (Microservices & API Gateways)

## 🎓 The RESHADED Framework
| Step | Letter | Action |
|------|--------|--------|
| 1 | **R** | Requirements (functional + non-functional) |
| 2 | **E** | Estimation (QPS, storage, bandwidth) |
| 3 | **S** | Storage schema design |
| 4 | **H** | High-level design |
| 5 | **A** | APIs |
| 6 | **D** | Detailed design |
| 7 | **E** | Evaluate bottlenecks |
| 8 | **D** | Deep dive a component |
