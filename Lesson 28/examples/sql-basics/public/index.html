Relational Databases & SQL

Learn how to store, query, and manage application data using Structured Query Language (SQL) and Relational Database Systems like PostgreSQL.

Tables

Data is organized into tables (like spreadsheets). Each Row is a single record (e.g., one user). Each Column is a property (e.g., email).

Primary Key

A column (usually id) that uniquely identifies every row. No two rows can have the same Primary Key.

PostgreSQL

A highly reliable, open-source Relational Database Management System (RDBMS). It runs on a server and responds to SQL queries.

Declarative

SQL is declarative: you write what data you want (e.g. "Select users where age > 18"), not how to loop over arrays to find it.

The 4 CRUD Operations in SQL

Every API route maps to one of these fundamental SQL commands.

CRUD SQL Command Example Syntax
Create INSERT INTO INSERT INTO users (name, age) VALUES ('Alice', 25);
Read SELECT SELECT * FROM users WHERE age > 18;
