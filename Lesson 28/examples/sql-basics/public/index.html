What is SQL?

SQL (Structured Query Language) is a declarative language for managing data in relational databases. You describe what data you want — the database figures out how to get it.

SELECT * FROM users
WHERE age > 18;

CRUD Operations

Every database interaction maps to one of four operations:

CREATE→ INSERT INTO
READ→ SELECT
UPDATE→ UPDATE SET
DELETE→ DELETE FROM

SQL Data Types

Every column must declare its data type — this enforces data integrity.

INTEGERWhole numbers
VARCHAR(n)Text up to n chars
TEXTUnlimited text
BOOLEANtrue / false
TIMESTAMPDate + time

Primary & Foreign Keys

A Primary Key uniquely identifies each row (usually id). A Foreign Key links one table to another — posts.user_id references users.id, creating a relationship.
