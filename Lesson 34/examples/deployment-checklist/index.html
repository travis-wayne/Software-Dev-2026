Taking Your App Live

It works on your machine... but now it needs to work for the world. Learn how to deploy Frontend apps to Vercel/Netlify, Backend APIs to Render/Heroku, and securely manage your Environment Variables.

🖼️

Frontend (Vercel, Netlify)

Static files (HTML, CSS, compiled JS). These hosts put your code on a CDN (Content Delivery Network) so it loads instantly anywhere in the world.

  • Process: `npm run build` is run by the host.
  • Output: A folder of static files (e.g., `dist` or `build`).
  • Scale: Infinite & very cheap.
⚙️

Backend (Render, Heroku)

A running Node.js server. These hosts provide a virtual machine or container that stays "awake" listening for HTTP requests.

  • Process: `npm start` keeps the server alive.
  • Needs: A `PORT` env var provided by the host.
  • Cost: More expensive (requires running CPU/RAM).
