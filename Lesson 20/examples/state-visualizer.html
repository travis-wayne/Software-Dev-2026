Pattern Quick Reference

Dependency Array

useEffect(() => { … }) → Every render
useEffect(() => { … }, []) → Mount only
useEffect(() => { … }, [count]) → Mount + when count changes
useEffect(() => { … return () => cleanup(); }, []) → Mount + cleanup on unmount

The Three States Pattern

Every data fetch should handle all three states. Never show a blank screen.

const [post, setPost] = useState(null); const [loading, setLoading] = useState(true); const [error, setError] = useState(null); // In JSX: if (loading) return <p>Loading...</p>; if (error) return <p style={{color:'red'}}>{error}</p>; return <div>{post.title}</div>;
