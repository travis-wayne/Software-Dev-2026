💡 Why Direct URLs Matter for Migrations

In serverless cloud databases like Neon PostgreSQL, normal API queries use a connection pooler (port 6543). However, migrations require persistent DDL advisory table locks. You MUST configure a separate DIRECT_URL (port 5432) in schema.prisma to prevent migrations from hanging!
