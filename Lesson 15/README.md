# Lesson 15: Project — To-Do List & Weather App

## Overview
This is the first **Project Session** of the course. Students apply all JavaScript fundamentals from Lessons 10–14 to build a complete, working web application of their choice.

## Projects Available
- **Option A: To-Do List App** — No API key required. Focuses on arrays, objects, DOM manipulation, event handling, and localStorage.
- **Option B: Weather App** — Uses the Fetch API with OpenWeatherMap. Focuses on async/await, API integration, and JSON data processing.

## Folder Structure
- `notes/` — Tutor guide and student project reference.
- `examples/todo-app.html` — ✅ Complete working To-Do List (reference implementation).
- `examples/weather-app.html` — ✅ Complete working Weather App (reference implementation).
- `exercises/project_planning.md` — Planning exercises and milestone checkpoints.
- `assignments/assignment_brief.md` — Project requirements and submission checklist.

## Concepts Applied
All JS fundamentals from Lessons 10–14:
- Variables, data types, operators (L10)
- Control flow, functions (L11)
- DOM manipulation, event handling (L12)
- Arrays, objects, ES6+ (L13)
- Async/Await, Fetch API (L14)

## Key Pedagogy
- **Pseudocode first, then code** — students plan before they type
- **One feature at a time** — milestone-driven development
- **`console.log()` as a tool** — not a crutch
