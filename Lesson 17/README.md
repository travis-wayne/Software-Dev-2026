# Lesson 17: Computer Science Basics — Data Structures (Stacks, Queues, Linked Lists)

## 🎯 Learning Objectives

By the end of this session, students will be able to:
1. Explain what a data structure is and why the choice of structure matters.
2. Describe LIFO and FIFO behaviour and identify which structure uses each.
3. Implement a **Stack** (push, pop, peek, isEmpty) in JavaScript.
4. Implement a **Queue** (enqueue, dequeue, peek, isEmpty) in JavaScript.
5. Implement a **Singly Linked List** (add, insertAtHead, remove, search, print) in JavaScript.
6. State the Big O time complexity of key operations for each structure.
